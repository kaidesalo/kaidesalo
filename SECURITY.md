# Security Policy

This repository hosts a static personal portfolio site (GitHub Pages).

## Reporting a vulnerability

Please report security issues privately via
[GitHub private vulnerability reporting](https://github.com/kaidesalo/kaidesalo/security/advisories/new)
rather than opening a public issue. I'll aim to acknowledge reports within a week.

## Scope

- The site content in this repository and its deployment at vulpibyte.dev.
- Third-party services (GitHub Pages, DNS providers) are out of scope; report those to the vendor.
