Project 01 / 03

Personal project · Web

Spellbranch

A web app for building Magic: The Gathering decks with friends: search cards, fork a deck into branches, and compare every change.

Screenshot · Landing page

Role

Solo designer/developer

Stack

Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Supabase, and the Scryfall API

Status

Public beta, live at spellbranch.vercel.app

Overview

Spellbranch is a Magic: The Gathering deck builder I’ve been building for my own lists, and for working on them with friends. It started as a card-sorting page. Each deck has Mainboard, Sideboard, and Maybeboard tabs, and a card’s printing can be swapped from a grid of printing tiles. Card search and card data come from the Scryfall API.

My Cards is the hub for Decks, Branches, and Collection, with a browse page for public decks and lists friends have shared. Deck stats show the mana curve, color requirements, type breakdown, and an estimated price. Lists import and export as pasted Moxfield or Archidekt lists. The core idea is still branching: fork a deck, try a different list, and compare that branch against the source so a game-night experiment never overwrites the original.

Screenshots are from the live public beta.
Project 02 / 03

Client project · Booking platform · Web

Clean Slate

A booking platform for a cleaning service: customers book as guests and only see times the team can actually staff, while staff run the schedule from a private dashboard.

Screenshot · Booking: available times

Role

Designer & developer (client project)

Stack

React 19, TypeScript, Vite 8, Tailwind CSS 4, React Router 7, date-fns; Vitest and Oxlint; a local demo data store for now, with a Supabase schema (Postgres, Auth, row-level security) and the supabase-js client included; Google Calendar, Resend, and Twilio adapters that run as mocks until configured

Data model

Ten Postgres tables in the Supabase migration: business users, employees, services, customers, appointments, quote requests, weekly employee availability, availability exceptions, notification logs, and business settings. Status enums track appointments and quotes, every table has row-level security turned on, and a GiST exclusion constraint stops one employee from holding two overlapping active appointments.

Status

In progress

Overview

Clean Slate is a booking platform for a cleaning service. Customers book as guests through a step-by-step flow (service, property, estimate or quote, schedule, contact, and review) and receive a management code they can use later to reschedule or cancel. Staff work from a private dashboard with appointments, a day/week/month calendar, employees, availability, services and pricing, and quote approvals.

Scheduling reliability is the core of the product. Available times are computed from business hours, employee schedules, appointment length, blocked time, and calendar busy periods, and each booking re-checks its slot before it’s saved so the same time can’t be double-booked. When the pricing rules can’t produce a confident estimate, the request becomes a custom quote instead.

The MVP runs on a local demo data store, with the Supabase schema, row-level security policies, and Vitest coverage for availability, pricing, and the booking lifecycle already in place. Calendar, email, and SMS integrations go through adapters that log mock output until real credentials are connected.

Next

  • Move guest booking writes to Supabase server-side functions
  • Connect Google Calendar, Resend, and Twilio through a server proxy
  • Roadmap: Stripe deposits and automated appointment reminders

Screenshots are from a local development build using the demo data store and sample customers. The repo is private.
Project 03 / 03

Fintech · Concept

Kitbook

A personal finance tracker concept that turns everyday spending into a clear, friendly picture of where your money goes, with a small origami fox keeping watch.

Concept image

Stack

React, TypeScript, D3.js, Node.js, PostgreSQL (concept stack)

Status

Concept (design mockup; all figures are sample data)

Overview

Budgeting tools tend to either bury people in spreadsheets or nag them with alerts. Kitbook explores how one calm overview (a balance, a monthly budget, spending by category, and a savings goal) can make money feel manageable instead of stressful.

Approach

  • A one-screen overview that answers the everyday questions first: how much is left, where it went, and whether a goal is on track.
  • Charts built with D3 and paired with plain-text labels and totals, so no figure is conveyed by color alone.
  • A typed data model for accounts, transactions, and budgets in PostgreSQL, shaped for fast monthly roll-ups.

Focus

Data Visualization · Product Design · Accessibility

Kitbook is a concept project. The dashboard above is a design mockup, and every figure in it is sample data.
