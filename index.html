Project 01 / 03

Personal project · Web

Spellbranch

A small web app for searching Magic: The Gathering cards and sorting them by color and set.

Concept image

Role

Solo designer/developer

Stack

Scryfall API; HTML, CSS, JavaScript

Status

In progress

Overview

Spellbranch is a Magic: The Gathering card-sorting webpage I’ve been meaning to ship for a while. The first version stays intentionally small: look up cards, then organize results by color and set so a pile of names becomes something you can actually browse.

It leans on the Scryfall API for card search and canonical card data, then applies simple front-end sorting for color and set. The goal is a clear, usable tool, not a full collection manager, so the core loop stays search, sort, scan.

I’m building it as a personal portfolio piece and a daily-driver for my own card lists. Scope for v1 is the search-and-sort flow; extras can wait until that path feels solid.

Next

  • Wire Scryfall search and render a clean results list
  • Sort and filter by color and set
  • Polish empty, loading, and error states plus mobile layout
  • Publish the repo and a live demo, then add screenshots here

Project 02 / 03

Personal project · Microsoft Teams

Foxforge

A Microsoft Teams app I’m scoping and scaffolding, built to live where conversations already happen.

Concept image

Role

Solo designer/developer

Stack

Microsoft Teams; Teams Toolkit, TypeScript, Node.js (planned)

Status

In progress

Overview

Foxforge is a Microsoft Teams app I’ve been putting off for longer than I’d like to admit. Rather than wait for the perfect plan, I’m starting small: write down what it should do, then get a bare app running inside Teams.

The first milestone is deliberately unglamorous: a written scope covering who it’s for, the one job it needs to do well, and what’s out of scope for v1, plus a minimal Teams scaffold that installs and runs end to end.

I’m building it as a portfolio piece and a way to learn how Teams apps are put together: the manifest, sideloading, and the platform’s conventions.

Project 03 / 03

Fintech · Concept

Kitbook

A personal finance tracker concept that turns everyday spending into a clear, friendly picture of where your money goes, with a small origami fox keeping watch.

Concept image

Stack

React, TypeScript, D3.js, Node.js, PostgreSQL (concept stack)

Overview

Budgeting tools tend to either bury people in spreadsheets or nag them with alerts. Kitbook explores how one calm overview (a balance, a monthly budget, spending by category, and a savings goal) can make money feel manageable instead of stressful.

Approach

  • A one-screen overview that answers the everyday questions first: how much is left, where it went, and whether a goal is on track.
  • Charts built with D3 and paired with plain-text labels and totals, so no figure is conveyed by color alone.
  • A typed data model for accounts, transactions, and budgets in PostgreSQL, shaped for fast monthly roll-ups.

Focus

Data Visualization · Product Design · Accessibility
